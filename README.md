I build and operate production software end to end — from schema design and cloud
infrastructure up to the web and mobile interface that users actually touch.

Most of my time goes into a **B2B SaaS platform for industrial construction
companies**. It integrates ERP APIs, consolidates operational data into a single
model and exposes it through a Next.js application and a set of LLM-powered agents
that answer questions and generate management reports. I am responsible for its
architecture, its AWS infrastructure (provisioned with Terraform), its CI/CD
pipelines and its day-to-day production operation — incidents included.

Alongside it I develop and publish **Firmo90**, a habit-recovery app available on the
App Store and Google Play. Built solo over the past year: React Native and
TypeScript on the client, Node.js and AWS behind it.

Before either of those, every line of code I wrote was for projects I started
myself. That is also why I care about the unglamorous parts — migrations that run
cleanly, pipelines that stay green, and a system that is still up at 7am.
