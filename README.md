I build and operate production software end to end — schema design, cloud
infrastructure, API, web and mobile.

Most of my time goes into a **B2B SaaS platform for industrial construction
companies**: a Turborepo monorepo of twelve applications — web, admin, landing,
mobile, a voice gateway and five background workers — that pulls data out of ERP
APIs, normalises it into a single model across multiple databases, and makes it
answerable through LLM-powered agents. I am responsible for its architecture, its
AWS infrastructure (provisioned with Terraform), its delivery pipeline and its
day-to-day production operation, incidents included.

Alongside it I build and publish **Firmo90**, a habit-recovery app on the App Store
and Google Play. Solo, over the past year: React Native and Expo on the client,
Express and PostgreSQL behind it, with subscriptions, push, realtime, localisation
and release automation to the stores.

Before either of those, every line of code I wrote was for projects I started
myself. That is also why I care about the unglamorous parts — migrations that run
cleanly, pipelines that stay green, and a system that is still up at 7am.
